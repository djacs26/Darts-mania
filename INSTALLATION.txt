DARTS MANIA — MISE À JOUR

Contenu :
- Mode équipes : choix manuel de l’équipe pour chaque joueur, nom personnalisable, exactement 2 joueurs par équipe et score partagé. Compatible avec 4, 6 ou 8 joueurs.
- Mode soirée : mêmes défis pour tous les participants sélectionnés ; chaque joueur joue ses 3 fléchettes ; validation automatique après la troisième ; 1 point si réussi, 0 si raté ; la roue ne change qu’après le passage de tous les participants.
- Annonces de tour dans tous les modes : « Au tour de [prénom] ! », sans énumération des autres joueurs ni annonce de fraction/classement.
- Voix au choix dans les réglages : mode normal avec commentaires et moqueries (par défaut), mode sérieux avec scores uniquement, ou mode muet. Le mode sérieux n’est jamais activé automatiquement.
- Le reste des fonctionnalités et le design existants sont conservés.

Installation : remplace les fichiers du site par ceux du dossier Darts-mania-main, puis actualise l’application. Le service worker est passé en v19 pour forcer le rechargement des fichiers.
